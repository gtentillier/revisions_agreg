Consignes de rédaction LaTeX : toutes les variables, ensembles etc. considérés seront clairement définis pour chaque théorème afin qu'il n'y ait pas d'ambiguité. utilise les notations abrégés autant que possible pour simplifier les énoncés : espaces de fonctions comme C1(I,R), R^N pour les suites réelles etc.
fonctions continues par morceaux : C_m

exemple :

Théorème du rang
Algèbre Linéaire

on veut le résultat suivant :

Soient $E$ et $F$ deux espaces vectoriels de dimension finie sur un corps $\mathbb{K}$. Soit $u \in \mathcal{L}(E, F)$ une application linéaire de $E$ dans $F$.
Alors :
$$\dim(E) = \dim(\ker(u)) + \text{rg}(u)$$
où $\ker(u)$ est le noyau de $u$ et $\text{rg}(u) = \dim(\text{im}(u))$ est le rang de $u$.

donc en remplaçant les sauts de ligne par '/n' on obtient le code LaTeX suivant :

Soient $E$ et $F$ deux espaces vectoriels de dimension finie sur un corps $\mathbb{K}$. Soit $u \in \mathcal{L}(E, F)$ une application linéaire de $E$ dans $F$./nAlors :/n$$\dim(E) = \dim(\ker(u)) + \text{rg}(u)$$/noù $\ker(u)$ est le noyau de $u$ et $\text{rg}(u) = \dim(\text{im}(u))$ est le rang de $u$.
